## Customer Accounts Microservice

This project develops a RESTful Customer Accounts microservice using Python and Flask.

The application supports creating, reading, updating, deleting, and listing customer accounts.

Technologies used include Python, Flask, PostgreSQL, GitHub Actions, Flake8, Nose, Docker, Kubernetes/OpenShift, and Tekton.

The project follows Agile planning, test-driven development, continuous integration, automated testing, security best practices, and continuous delivery.
